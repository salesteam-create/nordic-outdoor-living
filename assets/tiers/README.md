# Tier images

- `good.jpg`, `better.jpg`, `best.jpg`: product photos of each pod, used on the tier cards, in the configurator gallery, the buy bar and the order summary. Cropped to 3:2.
- `<tier>-ext-<color>.jpg`, `<tier>-cab-<color>.jpg`: color option thumbnails (Best reuses the Better ones).
- `top-<color>.jpg`: countertop color thumbnails.

Add-on thumbnails live in `assets/addons/`. Prices, features and dimensions per tier are in the `TIERS` and `ADDONS` data near the top of the main script in `index.html`.
